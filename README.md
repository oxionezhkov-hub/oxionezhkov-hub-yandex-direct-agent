# Директ-агент — скилл для Claude и Codex

Скилл превращает Claude Code или Codex в агента, который ведёт рекламу в Яндекс.Директе: собирает бриф, проверяет цели Метрики, подключает Директ, собирает и запускает кампании, каждый день убирает мусорные запросы и площадки, раз в неделю двигает ставки и присылает отчёт.

Вы отвечаете на вопросы и говорите «да». Деньги агент тратит только после вашего согласия.

## Что умеет

- **Бриф** — продукт, оффер, гео, бюджет, цена заявки. Сначала смотрит сайт сам, потом спрашивает недостающее.
- **Проверка цели** — сверяет цель Метрики с заявками в CRM, чтобы Директ не учился на мусоре.
- **Подключение** — Директ, Метрика, Вордстат через готовый MCP-сервер или свой доступ по API.
- **Сборка кампании** — спрос, группы фраз, заголовки и тексты под лимиты, баннеры, минус-слова, быстрые ссылки.
- **Запуск** — безопасные настройки, модерация, контроль первых 72 часов.
- **Автопилот** — каждый час расход и пауза при перерасходе, каждое утро минусация на согласование в Telegram, раз в неделю ставки, тексты и отчёт.
- **Аудиты и инсайты** — где утекают деньги и что с этим делать.

## Установка

### Claude Code — как плагин

```
/plugin marketplace add oxionezhkov-hub/oxionezhkov-hub-yandex-direct-agent
/plugin install direct-agent@yandex-direct-agent
```

### Claude Code — вручную

Скопируйте папку `plugins/direct-agent/skills/direct-agent` в `~/.claude/skills/direct-agent` (для всех проектов) или в `.claude/skills/direct-agent` внутри проекта.

```
git clone https://github.com/oxionezhkov-hub/oxionezhkov-hub-yandex-direct-agent
cp -r oxionezhkov-hub-yandex-direct-agent/plugins/direct-agent/skills/direct-agent ~/.claude/skills/
```

### Codex

Скопируйте ту же папку в `~/.codex/skills/direct-agent`:

```
cp -r oxionezhkov-hub-yandex-direct-agent/plugins/direct-agent/skills/direct-agent ~/.codex/skills/
```

### Приложение Claude

Заархивируйте папку `direct-agent` в zip и загрузите в настройках Claude, в разделе со скиллами.

## Как начать

Напишите агенту:

> Подключи мой Яндекс.Директ

или

> Запусти скилл «Директ-агент»

Дальше агент сам ведёт по шагам.

## Безопасность

- Без вашего «да» агент не меняет ставки, бюджеты, стратегии, минус-слова и не удаляет кампании.
- Сам он только ставит кампанию на паузу при перерасходе и сразу сообщает об этом.
- Токены хранятся в секретах, не в чате и не в файлах.
- Начинайте с доступа только на чтение.

Скилл опирается на сторонние MCP-серверы для Директа (askads, axisrow и другие). Перед установкой посмотрите их код и права.
